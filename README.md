# fudge (fundamentally under-developed game engine)

## What
This is (or is going to be) a simple game engine. I want to implement 2D and 3D scenes in it. I also want it to utilize [ECS](https://en.wikipedia.org/wiki/Entity_component_system).

The current idea is to implement window and input handling using SDL and graphics using Vulkan.

I also want to create an editor tool. This could be an in-engine tool that uses a bunch of IMGUI, but we'll see.

## Why
I want to try my hand a writing a game engine of some sort. The primary goal is to help me grow as a developer.
